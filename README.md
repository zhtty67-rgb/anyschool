# AnySchool · 人工智能基础

一个能跑的**学习诊断演示**：给你看「我卡在哪」和「这个数是怎么算出来的」。

打开 `dist/index.html` 就能用——数据已内联进页面，不需要服务器、不需要联网、不需要装任何东西。

---

## 这是什么

它不是又一个「刷题 App」。它想解决的问题是：

> **做错一道题之后，你其实不知道自己错在哪。**

普通题库告诉你「错了，正确答案是 C」。这个项目要做的是：
顺着知识点的先修关系往上追，找出你真正缺的那块地基，并且**把判断依据摊开给你看**——它引用了你哪几次作答、用了什么公式、算法版本是什么。

---

## 三个核心能力

### 1. 知识关系图

79 个人工智能概念、91 条先修关系，画成一张有方向的图。

- **箭头指向「下一个该学的」**，同一条线上的节点没有先后要求
- 每个方块是一个知识点，可以点开
- 有题可做的节点会显示题数

### 2. 掌握度，分母说清楚

界面顶部写「45 / 79 个知识点现在有题可做」。

这个 45 不是拍出来的：
- 知识树一共 79 个概念
- 题包覆盖 46 个
- 其中 1 个（c1103 变分自编码器）的 12 道题**本版没有放出**，原因是它的前置概念在整条学习路径上缺失，外行读不懂题干
- 所以实发 45 个

界面上那句话后面跟着解释，不会让你猜。

### 3. 每个数字都能点开看依据

点开任意一个节点，展开「这个数是怎么算出来的」：

```
算这个数用了哪几次作答    → 0 次
被排除的题              → 没有题被排除
公式参数                → decay=0.78;window=5;minSamples=3;mastered=0.8;weak=0.5
算法版本 / 算到什么时候   → mastery/1.0.0 · 2026-11-05T11:06:06Z
```

**不告诉你「你很薄弱」，而是告诉你「我根据这三道题判断你薄弱，这是公式」。**

## 数据格式

### 知识树 `data/concepts-ai.yaml`

```yaml
modules:
  - code: m01-ai-overview
    name: AI 概述
    concepts:
      - code: c0101
        name: 人工智能定义
        def: 研究如何让机器完成需要人类智能的任务。
        misconceptions:
          - 人工智能等于会说话的机器人
        prereq: []
```

`prereq` 是先修关系：学这个之前需要先学会什么。

### 题包 `data/questions-authoring-v11.jsonl`

每行一道题：

```json
{"id":"c0101-01","type":"single_choice","stem":"…","options":["…"],
 "answer":"C","explanation":"…","nodes":["c0101"],"misconception":"…"}
```

### 发布锁定 `published.json`

决定线上用哪一版题包。改 `path` 就切换版本，`build.mjs` 和所有脚本跟着走。

## 算法：掌握度怎么算

`core/mastery.mjs`：

```
score = Σ(decay^(n-i) × weight_i × hit_i) / Σ(decay^(n-i) × weight_i)
```

- 只看最近 5 次作答（`window=5`）
- 越近的权重越高（`decay=0.78`）
- 少于 3 次作答不给掌握度（`minSamples=3`），显示「判断不了水平」
- ≥ 0.8 判定已掌握，< 0.5 判定薄弱

**样本不足时返回 `unknown`，不给一个假的百分比。** 这是刻意的设计——宁可说不知道。

## 已知限制

**这个项目是原型，不是产品。** 具体地：

1. **只有 45 / 79 个知识点有题**，34 个概念有定义但没题
2. **题量小**：531 道题，每个有题节点约 12 道
3. **题目未经教师审核**：由 AI 生成 + 人工复核，但不保证教学适用性
4. **掌握度算法未用真实学生数据校准**，参数是拍的
5. **先修关系是教学设计，不是逻辑必然**：部分边反映的是教材顺序

**适合用来理解「诊断型学习系统长什么样」，不适合直接拿来教学。**

---

## 为什么公开

三个原因：

- **诊断逻辑值得被讨论**：把「凭什么说你薄弱」摊开，是可以被检验的
- **数据格式可以直接用**：`concepts-ai.yaml` + `jsonl` 是通用的，换学科就能用
- **失败的经验也有用**：`scripts/` 里那些跑不动的脚本，记录了当初是怎么验的

如果你要拿去做别的学科，改 `data/concepts-ai.yaml` 和题包就行，内核不用动。
